Computação e Rede - Resumo AZ-900
Introdução
Assisti às aulas do módulo da certificação AZ-900 que abordam Arquitetura e Serviços do Azure, com foco em computação e rede. Abaixo está um resumo dos principais tópicos aprendidos.

Principais Conceitos
Computação no Azure
Máquinas Virtuais (VMs)

Controle total sobre o sistema.

Ideal para migração "lift-and-shift".

Suporte a Windows e Linux.

Conjuntos de Dimensionamento de VMs

Escalabilidade horizontal automática.

Balanceamento de carga.

Área de Trabalho Virtual

Virtualização de desktop e aplicativos.

Acesso por navegador ou aplicativo dedicado.

Suporte para múltiplos usuários.

Contêineres

Leves e rápidos, ideais para microsserviços.

Gerenciamento facilitado sem necessidade de sistema operacional completo.

Tipos:

Instâncias de Contêiner (ACI) – PaaS para contêineres individuais.

Aplicativos de Contêiner – PaaS com escalabilidade e balanceamento de carga.

Serviço de Kubernetes (AKS) – Orquestração de contêineres em grande escala.

Azure Functions

Computação sem servidor (serverless).

Executa código sob demanda, sem manter infraestrutura ativa.

Serviços de Aplicativo do Azure

Plataforma gerenciada para criação de apps e APIs.

Suporte para várias linguagens (.NET, Java, Node.js, Python etc.).

Escalável, seguro e com requisitos corporativos.

Rede no Azure
Rede Virtual do Azure (VNet)

Conecta recursos do Azure entre si, com a Internet e com redes locais.

Suporte para sub-redes e segmentação personalizada.

Tipos de pontos de extremidade:

Públicos – acessíveis pela Internet.

Privados – acessíveis apenas dentro da rede.

Emparelhamento de Redes

Conexão entre redes privadas diretamente.

Serviços de Conectividade

Gateway de VPN – Tráfego criptografado via Internet pública.

ExpressRoute – Conexão privada por meio de um provedor.

DNS do Azure

Alta confiabilidade e desempenho com Anycast.

Gerenciamento centralizado de domínios.

Suporte a registros de alias para recursos do Azure.
